## Browser exercises
- Geographic Home and grouped setup selector opened against an isolated 605-user / 906-device synthetic fixture.
- Three-step personnel mapping was edited, reviewed, saved and reopened with its persisted area/reviewer/reason.
- The first save test exposed an invalid Reviewed status. Corrected to the governed Approved value. Added backend regression coverage for this save and stale-prior-value rejection; retest passed.
- Provisioning opened a 30-person synthetic run, paged 25/5, selected a person and edited a supervisor assignment.
- Saving produced a new revision and regenerated hashes. The saved supervisor email was verified visually, separate from supervisor UPN.
- Unsaved assignment edits disabled approval and blocked Home navigation with an actionable message.
- Approval advanced to Submit with the explicit nothing-submitted notice; submission was disabled without credentials.
- Small-screen width checked at 390 pixels with no document-wide horizontal overflow in Preview. Native desktop rendering and 768-pixel geographic rendering were inspected. Grid overflow is intentionally contained within the intake table.
- No JavaScript error logs were reported for the inspected current tabs.

Tests used local synthetic fixture processes, not an operational workspace. The new read-only role endpoint was tested both with and without an authenticated local session.

## Visual fidelity ledger
Frontend App Builder skill applied: shared token/component specification, native React implementation, concept and actual screenshot review.

| Reference property | Implemented observation | Intentional deviation / limitation |
|---|---|---|
| White canvas with navy headings and blue actions | Shared theme across both applications | Existing specialized charts and data-table styles retained |
| Horizontal task navigation | Home/People/Devices/Locations/Reports in Geographic | Provisioning has its own smaller navigation because process authentication remains separate |
| Open task rows separated by fine rules | Home has task descriptions and clear action labels | No fictional device counts or concept-only recent activity |
| Continuation rail | Actual current provisioning revision and saved-resource context | Stacks beneath tasks on narrower screens |
| Guided three-step location decision | Choose, confirm, review/save with contextual explanation | Reviewer and reason are explicit governance requirements |
| List-and-detail review | 25-person pages with one assignment editor | Replaces the all-fields-wide table; preserves advanced bulk editing |
| Muted optional guidance | Location/AOR/category and Group remain visibly optional | No implication that optional mappings block a user import |

Copy changes from concepts: Geographic Home says Find a device or assignment; account creation is in Provisioning Center. Reports does not promise leadership redaction. Review status is Approved at the data boundary. Current baseline timestamps replace illustrative concept dates.

Synthetic rendered screenshots are separate review artifacts, not bundled personnel data. Compared the Task Home and Guided Tasks concept images with actual home and mapping renders. Full-page in-app screenshots showed stitching/scale artifacts at oversized viewports, so native viewport captures were used. Pixel-perfect fidelity at the original 1536 x 1024 concept dimensions is not claimed.
